## Project Overview
This repository (`overtime-js`) is an Overtime Pay & TER Tax Calculator web application built with **React 19** and **Tailwind CSS**.

## Key Guidelines & Rules

1. **Working Branch:** `miiovt-main`.
2. **Commands:**
   - Dev Server: `npm start`
   - Build: `npm run build`
   - Test: `npm test`
3. **Core Files:**
   - [src/App.js](file:///c:/Vibe/overtime-js/src/App.js): Core application logic and UI.
   - [src/terData.js](file:///c:/Vibe/overtime-js/src/terData.js): TER tax rates database.
   - [package.json](file:///c:/Vibe/overtime-js/package.json): Project metadata and scripts.
4. **Code Quality:**
   - Use standard functional React patterns with Hooks.
   - Ensure accurate financial and overtime formula calculations.
   - Run build/test verification after significant code modifications.
